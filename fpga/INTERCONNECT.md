# QSSC — FPGA ↔ peripherals: interconnect map

Tables showing how the FPGA is wired to each driver. Three ball columns:

| Column | Meaning |
|---|---|
| **CSG324** | custom QSSC board, XC7A35T-1CSG324C — from `fpga/constraints.xdc` |
| **QMTECH** | XC7A15T-**CSG325** test board — from `fpga/qmtech/constraints_qmtech.xdc` |
| **IC pin** | pin on the peripheral — from [`hardware/datasheets/DATASHEETS.md`](../hardware/datasheets/DATASHEETS.md) |

Authoritative source for the CSG324 balls: `.tmpwork/fpga_csg324_map.json`,
generated by `tools/gen_fpga_ballmap_csg324.py` and written into the XDC by
`tools/gen_xdc.py`. Per-ball detail for the QMTECH is in
[`qmtech/PINMAP.md`](qmtech/PINMAP.md).

## 1. ADF4351 — microwave PLL (U3, QFN-32)

4-wire SPI bus plus a 25 MHz reference clock.

| RTL signal | Dir | Net | CSG324 | QMTECH | ADF4351 pin |
|---|---|---|---|---|---|
| `spi_pins[0]` | FPGA-> | `SPI_LE` | **G1** | JP2-11 (R5) | 3 — **LE** (latch enable) |
| `spi_pins[1]` | FPGA-> | `SPI_CLK` | **E1** | JP2-12 (T4) | 1 — **CLK** |
| `spi_pins[2]` | FPGA-> | `SPI_DATA` | **F1** | JP2-13 (U6) | 2 — **DATA** |
| `spi_pins[3]` | FPGA<- | `ADF_MUXOUT` | **H1** | JP2-14 (U5) | 30 — **MUXOUT** (lock detect) |
| `refclk_out` | FPGA-> | `refclk_25m` | **A8** | JP2-15 (V4) | 29 — **REFIN** |

- `refclk_out` is a **25 MHz** square wave = `clk_100mhz / 4` (`refclk_div`
  in `top_level.v`).
- The ADF4351 has **no `REFIN-`**: the reference is **single-ended** on
  pin 29.
- `MUXOUT` enters on `spi_pins[3]`, is 2-FF synchronised and deglitched
  (audit #98).
- Strapped on the PCB (not XDC I/O): `CE=4->+3V3`, `PDB_RF=26->+3V3`
  (active-low -> RF always enabled), `RSET=22->4.7k->GND`,
  `TEMP=19->C37 100nF`, `VREF=24->C36 100nF`, `LD=25->NC`.

> ⚠️ **Documentation erratum:** `hardware/datasheets/DATASHEETS.md` (lines 71
> and 108) says REFIN comes from ball **A14**. It is **A8**: both
> `constraints.xdc:128` and the generated map agree. A14 is wrong.

## 2. TLC5947 x3 — 64-emitter driver (UE0/UE1/UE2)

4 wires, daisy-chained `SIN -> SOUT` for 72 channels (64 used).

| RTL signal | Dir | Net | CSG324 | QMTECH | TLC5947 pin |
|---|---|---|---|---|---|
| `em_sclk` | FPGA-> | `em_sclk` | **V1** | JP2-3 (V8) | 3 — **SCLK** |
| `em_sin` | FPGA-> | `em_sin` | **V2** | JP2-4 (V7) | 4 — **SIN** (chip0) |
| `em_xlat` | FPGA-> | `em_xlat` | **V4** | JP2-5 (U7) | 30 — **XLAT** |
| `em_blank` | FPGA-> | `em_blank` | **V5** | JP2-6 (V6) | 2 — **BLANK** |

- Chain: `chip0.SIN <- FPGA`, `chip0.SOUT(29) -> chip1.SIN`,
  `chip1.SOUT -> chip2.SIN`.
- Shifts **864 bits**, channel 71 (chip2 OUT23) **MSB first** ->
  channel 0 (chip0 OUT0) LSB last.
- No `Gsclk` pin: the grayscale PWM oscillator is **internal** (4 MHz).
- Per channel: 12 bits of PWM. Emitter cathode = `OUTn`; common anodes =
  `EM_ANODE` -> **+12V_EMIT** rail (J4 -> F2 -> C85/C86).
- `I_OUT = 41 x 1.20 / R_IREF`, with `Riref = 4.87 kΩ` -> **~10.1 mA**.
- `OUTn` tolerates up to **33 V / 38 mA** at VCC = 3.3 V, which is why a 12 V
  rail is compatible with 3.3 V logic.

## 3. AD7616 x4 — parallel readout of 64 detectors (UAD0..UAD3)

9-wire SPI bus. The signals do **not** reach the ADCs directly: they cross
the board-to-board connector **J12** (main <-> head board).

| RTL signal | Dir | CSG324 | QMTECH | J12 pin | AD7616 pin |
|---|---|---|---|---|---|
| `adc_convst` | FPGA-> | **A18** | JP3-3 (F18) | 3 | **CONVST** (conversion start) |
| `adc_sclk` | FPGA-> | **B18** | JP3-5 (E18) | 5 | **SCLK** |
| `adc_miso` | FPGA<- | **D18** | JP3-7 (D18) | 7 | **DOUT/RD** (SDOA) |
| `adc_busy` | FPGA<- | **E18** | JP3-9 (C17) | 9 | **BUSY** |
| `adc_resetn` | FPGA-> | **M18** | JP3-13 (F15) | 11 | **RESET** (active-low) |
| `adc_cs[0]` | FPGA-> | **F18** | JP3-8 (E17) | 13 | **CS** (UAD0) |
| `adc_cs[1]` | FPGA-> | **G18** | JP3-10 (C18) | 14 | **CS** (UAD1) |
| `adc_cs[2]` | FPGA-> | **J18** | JP3-11 (G15) | 15 | **CS** (UAD2) |
| `adc_cs[3]` | FPGA-> | **L18** | JP3-12 (H16) | 16 | **CS** (UAD3) |

J12 in full: `1,4,6,8,10,12,19,20 = GND` (every signal ground-flanked),
`2 = +3V3`, `17,18 = +5V`.

- `adc_busy` is taken **from UAD0 only** (push-pull): all four finish the
  same CONVST simultaneously.
- The **±5 V** range is strapped in hardware, hence **no MOSI and no
  configuration writes**.
- `adc_sclk` is a **gated strobe** (100/8 = 12.5 MHz), not a continuous
  clock -> it is deliberately not declared `create_generated_clock`.

## 4. MCP4921 — field-gradient DAC (Ugrad, SOIC-8)

| RTL signal | Dir | CSG324 | QMTECH | MCP4921 pin |
|---|---|---|---|---|
| `grad_cs` | FPGA-> | **V6** | JP2-7 (T7) | 2 — **!CS** |
| `grad_sclk` | FPGA-> | **V9** | JP2-8 (R7) | 3 — **SCK** |
| `grad_mosi` | FPGA-> | **V12** | JP2-9 (R6) | 4 — **SDI** |
| `grad_en` | FPGA-> | **V7** | JP2-10 (T5) | — **not connected** |

- ⚠️ **`grad_en` does not go to any DAC pin** — that ball is `NC` on the PCB;
  it is a status output reserved for a possible future high-side enable.
  `dac_ctrl.v` does not depend on it.
- `!LDAC = 5 -> GND` (transparent: updates on `!CS` rising).
- SPI write word: **`{4'b0011, code[11:0]}`** -> bit15=write,
  bit14=unbuffered VREF, bit13=1x gain, bit12=!SHDN active.
- The 8-pin MCP4921 has **no !SHDN pin**: powering down means writing code 0
  -> `VOUTA = 0` -> LM358 -> MOSFET off.
- Chain: `VOUTA(8) -> LM358 INA+ -> OUTA -> IRLML2502 gate`, closed by the
  `1 Ω` sense resistor (`GRAD_SENSE`), `I = Vdac / 1 Ω`.

## 5. UART — FT232RL (J1)

| RTL signal | Dir | CSG324 | QMTECH | FT232RL pin |
|---|---|---|---|---|
| `rx` | FPGA<- | **C1** | JP2-18 (V2) | 1 — **TXD** (FT232 transmitter) |
| `tx` | FPGA-> | **B1** | JP2-19 (U2) | 5 — **RXD** (FT232 receiver) |

115200 baud, 8-N-1 -> `CLKS_PER_BIT = 868` at 100 MHz.
XDC names are FPGA-perspective: the FT232 `TXD` drives the FPGA `rx` line.
The QMTECH has **no onboard FT232** — plug a USB-UART adapter into JP2-18/19
(or run the FT232H in UART mode).

## 6. Remaining signals

| RTL signal | Dir | CSG324 | QMTECH | Function |
|---|---|---|---|---|
| `clk_100mhz` | in | **B8** | — (R2, 50 MHz) | System clock. CSG324: 100 MHz **ASE-100MHz** TCXO on an MRCC pin. QMTECH: 50 MHz -> MMCM in `top_qmtech.v` |
| `reset` | in | **A1** | `key0_n` H18 | CSG324: active-high push button. QMTECH: SW1 ACTIVE-LOW with a 4.7k pull-up, inverted in the wrapper |
| `mod_sync` | out | **K1** | JP2-17 (V3) | **1 kHz** lock-in reference (host-side I/Q demodulation) |
| `mw_gate` | out | **L1** | JP2-16 (U4) | RF-switch gate pulse (`APPLY_PULSE`) between ADF4351 and antenna |

## 7. Configuration and JTAG

### Custom board (CSG324)

| Function | Ball |
|---|---|
| JTAG `TCK` | **E10** |
| JTAG `TDI` | **E11** |
| JTAG `TDO` | **E13** |
| JTAG `TMS` | **E12** |
| `CCLK` | E9 |
| `D00 / D01 / D02 / D03` | K17 / K18 / L14 / M14 |
| `FCS_B` | L13 |
| `DONE` | P10 |
| `INIT_B` | P7 |
| `PROGRAM_B` | P9 |
| `M0 / M1 / M2` | P12 / P13 / P11 |

JTAG header **J9** (2x5, standard Xilinx): 1=TCK, 3=TDO, 5=TMS, 7=TDI,
even pins=GND, **9=VREF=+3V3**, 10=GND.
Config flash: **W25Q128** (128 Mbit, QSPI).

### QMTECH (CSG325) — do not mix these up

| Function | CSG324 | **QMTECH** |
|---|---|---|
| JTAG `TCK` | E10 | **F8** |
| JTAG `TDI` | E11 | **T9** |
| JTAG `TDO` | E13 | **T8** |
| JTAG `TMS` | E12 | **R8** |
| `CCLK` | E9 | **E8** |
| `DONE` | P10 | **F12** |
| `PROGRAM_B` | P9 | **P10** |

JTAG header **J1** (1x6): 1=3V3(VREF), 2=GND, 3=TCK, 4=TDO, 5=TDI, 6=TMS.
Flash: **N25Q64** (64 Mbit, quad). Boots Master SPI (`M[2:0]=1:0:0`).

> Note `PROGRAM_B` is **P9 on CSG324 but P10 on CSG325**, and `DONE` moves
> from **P10 to F12**: different packages, the balls cannot be reused.

## 8. Differences when porting to QMTECH — summary

1. **Different package** (CSG325 vs CSG324): different ball map.
2. Custom-board XDC balls that are **ground** on CSG325: `B8, A18, B18, G1, A8`.
3. Balls **not brought out** on JP2/JP3: `A1, B1, C1`.
4. Clock **100 MHz (B8) -> 50 MHz (R2)** => an MMCM is required.
5. Reset **active-high (A1) -> active-low (H18)** => must be inverted.
6. On-board LEDs and buttons, both active-low.
7. `em_*` moves from **V1/V2/V4/V5** to **V8/V7/U7/V6** (JP2-3..6).
8. `grad_*` moves from **V6/V9/V12/V7** to **T7/R7/R6/T5** (JP2-7..10).
